# 演示样稿说明

`customer-service-agent-demo.html` 是用于 README 展示的独立 HTML 样稿。它展示本技能应产出的核心阅读体验：

- 研究标题、摘要、关键词和章节层级；
- 表格与机制图；
- 术语首次解释与可点击术语表；
- 文内编号引文与参考文献结构；
- 桌面阅读、窄屏适配和 A4 打印样式。

## 内容与隐私边界

该样稿是为展示而编写的虚构案例。企业名称、场景细节、指标、资料和参考文献均为示意，不对应任何真实客户、组织、产品部署、个人或既有研究。它不包含用户提供的材料、访问记录、本地路径、账户信息或密钥。

请勿将样稿中的“演示资料”视为可引用来源。实际研究报告应按照 `SKILL.md` 的要求核验一手资料，并以真实、可访问的文献替换示例引用。
